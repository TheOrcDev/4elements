# The Four Elements

Fire &middot; Air &middot; Water &middot; Earth — an interactive Three.js scene with custom GLSL shaders, GPU particles, and bloom post-processing.

## Run

```bash
npm install
npm run dev
```

Then open http://localhost:5173

## Controls

- **Drag** to orbit, **scroll** to zoom
- **1–4** (or click an element / the dock buttons) to summon a single element
- **0** / **Esc** to return to the full view

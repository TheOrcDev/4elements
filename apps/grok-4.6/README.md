# The Four Elements

A cinematic Three.js sanctum of **fire**, **air**, **water**, and **earth**, built with Vite.

## Run locally

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually `http://localhost:5173`).

## Controls

- Drag to orbit, scroll to zoom
- Dock buttons or keys `1`–`4` to focus an element
- `0` returns to the overview

## Stack

- Vite
- Three.js with custom GLSL shaders, particles, and bloom

# Primordia — Atlas of Elements

An interactive Three.js study of fire, air, water, and earth, built with Vite.

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. Use the element rail to switch models, drag to orbit, scroll to zoom, and use the viewer controls to pause rotation, reset the camera, or enter fullscreen.

## Production build

```sh
npm run build
```

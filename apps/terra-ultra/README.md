# Elemental Sanctum

An interactive Three.js scene that gives each classical element its own animated, procedural form:

- **Fire** — ascending embers, heat glow, and a pulsing core
- **Air** — luminous, orbiting wind ribbons and drifting motes
- **Water** — a refractive sapphire orb with rotating wave rings and droplets
- **Earth** — levitating faceted stone, crystal veins, and orbiting fragments

## Run locally

```bash
pnpm install
pnpm dev
```

Then open the local URL shown by Vite (usually `http://localhost:5173`).

## Controls

- Drag to orbit the sanctuary
- Scroll to zoom
- Select an element from the bottom navigation, click its 3D form, or press `1`–`4`

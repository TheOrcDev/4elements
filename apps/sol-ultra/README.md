# Primal — The Four Elements

An immersive real-time Three.js study of fire, air, water, and earth, built
with React and Vite.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Controls

- Select an element in the bottom field guide or press `1`–`4`.
- Drag across the scene to orbit the composition.
- Scroll to adjust distance.
- Press `Escape` or `O` to return to the overview.
- Use the left and right arrow keys to move between elements.

## Validation

```bash
npm test
```

The production bundle is written to `dist/`.

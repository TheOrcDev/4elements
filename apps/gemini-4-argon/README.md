# The Four Elements

A polished Three.js scene of **fire**, **water**, **earth**, and **air**, built with Vite.

## Run locally

```bash
pnpm install
pnpm dev
```

Then open the URL Vite prints.

## Controls

- Drag to orbit, scroll to zoom
- Click an element name to focus the camera on it

## Stack

- Vite
- Three.js with custom GLSL materials, particle systems, and unreal bloom
